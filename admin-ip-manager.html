كيفية استخدام النظام:

  • الـ IP هو عنوان الإنترنت الخاص بجهازك
  • يمكنك إضافة أكثر من IP (منزل، عمل، جوال)
  • للعثور على IP جهازك: whatismyip.com
  • الـ IP المنزلي عادة يتغير عند إعادة تشغيل الراوتر
  • لـ IP ثابت، راسل مزود الإنترنت أو استخدم VPN
  • النظام الجديد يعتمد على بصمة الجهاز + OTP للأمان
